## 🌸 About me

- 🎮 I build games & bots — Unity game AI, LLM chat apps and QQ bots
- 🤝 How I work: I design, make the calls and test; [Claude Code](https://claude.com/claude-code) writes much of the code

- 👻 Yes, the profile theme is Hu Tao. No, I will not apologize

## 🔥 What I've been building

- 🧟 **[Waste Land 2039](https://github.com/KahootGenius/WasteLand2039)** — my Unity zombie-survival game, and an experiment: can a horde learn where *you* run and be waiting there? Reinforcement learning got lethal but never learned to anticipate; a small predictive model did, and its newest version does 12% more damage than the last in a pre-registered test
- 💌 **[LoveSeek](https://github.com/KahootGenius/OpenLoveSeek)** — an Android AI companion whose characters keep a schedule, a mood and a memory, and reply when they'd actually see your message. v1.0 to v3.0 since July, 654 tests, no server and no account
- 🤖 **[小莲](https://github.com/KahootGenius/XiaoLianBot)** — a QQ group bot: the group's caretaker, who enforces its 30-day activity rule with safety rails, runs the team games and chats in character
- 🃏 **[RL-for-KARDS](https://github.com/KahootGenius/RL-for-KARDS)** — a KARDS-style card-game engine, and bots that learn it by playing themselves; the Transformer policy beats a lookahead-search bot in 91.6% of games
- 🧮 Earlier: an [HSR damage calculator](https://github.com/KahootGenius/Honkai-Starrail_Damage_Calculator), [Castorice bot](https://github.com/KahootGenius/Castorice_bot) (小莲's ancestor) and [Storix-Web](https://github.com/KahootGenius/Storix-Web)

📖 The longer story, what I build and why, lives in my **[portfolio](https://github.com/KahootGenius/portfolio)**.
